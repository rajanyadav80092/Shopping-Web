# 🛒 Shopping App

A backend-focused shopping application built with Flask and SQLAlchemy.
The project demonstrates REST API development, authentication,
database relationships, migrations, role-based access control,
order management and backend validation.

## 🚀 Features

- User registration and login
- Password hashing
- JWT-based authentication
- Role-based access control
- User management
- Order creation and management
- User-Order relationship
- SQLite database
- SQLAlchemy ORM
- Database migrations using Flask-Migrate/Alembic
- Request validation
- REST APIs
- Blueprint-based project structure
- Redis caching
- Error handling
- Post/Redirect/Get pattern

## 🛠️ Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Migrate
- Alembic
- Flask-JWT-Extended
- Flask-WTF
- SQLite
- Redis
- HTML/CSS/JavaScript
